# CSV Cleaner

Open a messy CSV file and get a clean one back.

## What it fixes

- Removes extra spaces around values.
- Removes rows that are completely empty.
- Removes exact duplicate rows.
- Tidies column names (trims them, and fills in blank ones).

Choose a file, pick the fixes you want, preview the result, then save the cleaned file.
Recent files stay in the sidebar so you can save them again later. Nothing is uploaded anywhere.

## Permissions

- **Can read files you choose** — to open the CSV you pick.
- **Can save files where you choose** — to save the cleaned CSV.
